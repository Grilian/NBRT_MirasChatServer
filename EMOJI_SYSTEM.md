# Новая система эмодзи MirasChat

## Как устроено

- В сообщении хранится обычный Unicode (`😀`, `🇦🇨`, `👩‍💻`), а не технический `:u_...:`.
- Один логический эмодзи определяется полной последовательностью кодовых точек.
- Apple и Google Fonts — базовые оформления. Активно одно, но если в нём нет файла, клиент автоматически берёт его из следующего включённого базового набора (обычно Apple).
- Telegram Animation — анимационный слой. Если файл для конкретного Unicode есть и пользователь не отключил анимации, он показывается поверх базового оформления.
- Категории, порядок, названия и ключевые слова отделены от картинок и загружаются отдельным файлом.

## Загрузка картинок

В панели супер-админа откройте «Смайлики» → «Наборы изображений»:

1. Выберите Apple, Telegram Animation или Google Fonts.
2. Выберите ZIP с изображениями.
3. Дождитесь итогового счётчика. Сервер конвертирует изображения в WebP; для Telegram сохраняются все кадры.

Поддерживаемые имена файлов:

- `U+1F600.webp`
- `u_1f600.png`
- `U+1F1E6-U+1F1E8.webp`
- `U+1F469-200D-1F4BB.gif`

Регистр букв и расширение не важны. Вложенные папки внутри ZIP разрешены.

## Структура сортировки

Можно загрузить официальный `emoji-test.txt` Unicode либо JSON:

```json
{
  "items": [
    {
      "code": "1F600",
      "emoji": "😀",
      "group": "Смайлики и эмоции",
      "subgroup": "Улыбающиеся лица",
      "name": "Улыбающееся лицо",
      "keywords": ["улыбка", "радость", "привет"]
    },
    {
      "code": "1F1E6-1F1E8",
      "emoji": "🇦🇨",
      "group": "Флаги",
      "subgroup": "Страны",
      "name": "Остров Вознесения",
      "keywords": ["флаг", "остров"]
    }
  ]
}
```

Структуру можно применять повторно: картинки останутся на месте, изменятся только категории, порядок и поиск.

Рекомендуемый порядок первоначальной настройки:

1. Загрузить структуру.
2. Импортировать Apple.
3. Импортировать Telegram Animation.
4. При необходимости импортировать Google Fonts и сделать его активным.

Если сначала загрузить картинки, а структуру потом, результат будет тем же.

## Старые сообщения

Кнопка «Заменить старые :u_...: в сообщениях» однократно переводит известные технические коды в обычный Unicode. Произвольные пользовательские смайлики `:name:` она не меняет.

## Предложения и поиск

- Пикер ищет сразу во всех категориях по названию, ключевым словам, Unicode-коду и самому символу.
- Когда пользователь заканчивает ввод слова, над полем показываются подходящие эмодзи.
- Встроены базовые русские синонимы для частых эмоций; полноценные подсказки лучше задавать полем `keywords` в JSON-структуре.
